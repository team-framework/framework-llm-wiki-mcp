# 로그인 재검증 정책

팀원이 GitHub로 로그인하면 서버가 조직 멤버십이 active이고 역할이 member 또는 admin인지 확인한다. OAuth MCP 연결은 그 확인 시점부터 24시간을 재로그인 상한으로 사용한다. refresh를 여러 번 사용해도 최초 상한을 연장하지 않는다.

access token은 최대 1시간이다. 24시간 상한까지 남은 시간이 1시간보다 짧으면 access token도 그 상한에 만료된다. refresh token은 최초 상한에 만료되며, 상한 정보가 없는 이전 refresh token은 새 GitHub 로그인을 요구한다.

브라우저 로그인 쿠키는 1시간이다. 서버는 OAuth refresh·authorization code를 브라우저 쿠키로 사용하는 요청을 거절한다. 이전 형식의 정상 쿠키는 남은 유효 시간이 1시간 이내일 때 유지한다.

이 정책은 팀 탈퇴를 실시간으로 감지하지 않는다. 탈퇴 직전에 멤버십 확인을 통과한 MCP 연결은 최초 로그인 후 최대 24시간, 브라우저 쿠키는 최대 1시간 동안 남을 수 있다. 상한 뒤의 GitHub 로그인에서 현재 멤버십을 다시 확인한다. OAuth 토큰을 보관하거나 조직 조회용 App 권한을 새로 요청하지 않는다.
